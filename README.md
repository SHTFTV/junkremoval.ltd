# JunkRemoval.ltd

Independent editorial publication about household clearouts, reuse, material routing and professional removal operations. Not an operating collection company.

## Deployment

Static source in the repository root, deployed to Vercel project `prj_sYtdymBvXBDUWE1QyV7lmS0GJ9iR`, canonical https://junkremoval.ltd. No package install/build required. `vercel.json` sets clean URLs and trailing slashes.

## Content and operations

16 sourced guides, each over 2,000 body words; original clearly labelled editorial illustrations; a browser-only downloadable clearout planner. `site-sot.json` is the canonical site scope; `publication-status.json` records post metadata; `role-evidence.json` remains red until actual unattended receipts are verified. No unattended publisher or independent watchdog is claimed by this build.

Contributions use the public GitHub issue form. Do not submit private customer information. No commercial intake or booking form exists.
